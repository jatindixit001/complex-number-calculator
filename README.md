# complex number calculator
Complex Number Calculator in C++

About the Project

The Complex Number Calculator is a C++ mini-project developed using Object-Oriented Programming (OOP) concepts. It performs addition and subtraction of two complex numbers using operator overloading.

Features

- Stores real and imaginary parts using a "Complex" class.
- Overloads the "+" operator for addition.
- Overloads the "-" operator for subtraction.
- Overloads the "<<" operator to display complex numbers.
- Accepts input from the user.

OOP Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Operator Overloading
- Friend Function

Technologies Used

- Programming Language: C++
- Concepts: Object-Oriented Programming

How to Run

1. Download or clone this repository.
2. Compile "main.cpp" using a C++ compiler.
3. Run the compiled program and enter the real and imaginary parts of both complex numbers.

Sample Output

First Number: 5 + 3i
Second Number: 2 + 4i
Addition: 7 + 7i
Subtraction: 3 - 1i

Conclusion

This project demonstrates how operator overloading and other OOP concepts can be used to perform arithmetic operations on complex numbers in C++.
